# Contrato de task

Usar [template](templates/TASK_TEMPLATE.md). Campos obrigatórios:
PROJECT, FRONT, PARENT_TOPIC, objetivo/benefício, subtópicos, limites,
READ/CREATE/MODIFY, baseline Git, branch/worktree, ownership, critérios objetivos,
validações e evidências, riscos, autorização externa e próximos passos.

Separar status técnico, Git e operacional. Estados técnicos:
PLANNED, IN_PROGRESS, DONE, PARTIAL ou BLOCKED com causa verificável.
UNVERIFIED descreve evidência ausente, nunca sucesso presumido.

Para tokens/componentes: API afetada, consumidores conhecidos, tema/teclado,
licença, compatibilidade, alteração de versão e migração. Teste de risco real,
sem criar testes que apenas repitam a implementação.
