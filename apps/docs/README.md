# Catálogo local — escopo preparado

Este diretório reserva um workspace com finalidade concreta: catálogo offline
da biblioteca, sem códigos de produtos. Não existe aplicação executável aqui.

Na implementação futura, cada componente terá: propósito, props, estados,
variantes, teclado, nome acessível e exemplos explicitamente fictícios.
Mostrar temas lado a lado e aninhados, dark/light, português, labels longos,
densidade, reflow e movimento reduzido. Não depender de APIs reais ou fontes
remotas. Documentar portais e origem de cada tema.

Decidir ferramenta de documentação no NX-DS-002 conforme necessidade demonstrada;
não instalar Storybook ou frameworks apenas para manter esta estrutura.
