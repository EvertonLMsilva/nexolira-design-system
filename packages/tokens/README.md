# @nexolira/tokens 0.2.0

Pacote local, privado e ESM. A entrada principal exporta tokens, resolvedTokens, compileTokens, resolveToken, cssName e TokenModel. O JSON está em `@nexolira/tokens/tokens.json` e a folha de estilos em `@nexolira/tokens/styles.css`. O pacote funciona sem React.

Use `class="nx-scope" data-nx-theme="mktauto" data-nx-mode="light"` no host. Também estão disponíveis MKTauto escuro e Nexolira claro/escuro. A ausência de atributos no host .nx-scope preserva o padrão Nexolira escuro. A versão acrescenta papéis para sidebar e seleção e conserva os valores Nexolira anteriores. Importe a folha de tokens antes de `@nexolira/ui/styles.css`.

Instalação local: `npm install ./nexolira-tokens-0.2.0.tgz`. UNLICENSED.
